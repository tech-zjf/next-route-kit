# next-route-kit 0.1.0

[English release notes](../../release/v0.1.0.md) · **简体中文**

状态：首个公开基线版本。

## 发布包

| 包                        | 用途                                       | 安装                                  |
| ------------------------- | ------------------------------------------ | ------------------------------------- |
| `next-route-kit`          | Next.js App Router Route Factory 和输入源  | `pnpm add next-route-kit`             |
| `@next-route-kit/core`    | 与框架无关的契约和 Pipeline Runtime        | `pnpm add @next-route-kit/core`       |
| `@next-route-kit/zod`     | 可选的 Zod 4 校验适配器                    | `pnpm add @next-route-kit/zod zod`    |
| `@next-route-kit/testing` | 与测试框架无关的 Request/Response 测试工具 | `pnpm add -D @next-route-kit/testing` |

## 包含的能力

首版保留原生 `app/**/route.ts` 约定，并提供以下请求链路：

```text
Next params hydration
  → Middleware
  → Guard
  → Interceptor (enter)
  → declared body/query resolution
  → Pipe
  → Handler
  → Interceptor (exit)
  → Middleware (exit)
  → Response Serializer
```

Factory 使用 class 实现并保持不可变，支持 Global → Scope → Route 的显式组合。本版本中，继承的安全组件不能被子路由移除。

## 兼容性

已验证 Next.js 15.5.23 和 16.3.1，包括两个版本的 Node Route Handler、Next 15 的
Edge Route Handler、异步动态 params、生产构建和 Turbopack 开发服务器。详情见[兼容性矩阵](../../compatibility/next-matrix.md)。

## 校验与错误

- Core 不绑定具体校验库。
- `@next-route-kit/zod` 面向 Zod 4，使用异步解析。
- 主包不会安装或注册 Zod；使用统一 API 外壳时，通过
  `apiResponsePlugin({ mapError })` 映射 `ZodValidationError`。
- 主包默认处理 `HttpError` 和非法 JSON。
- 自定义 ExceptionFilter 优先于内置 Filter。
- 未知异常继续交给 Next.js 错误边界处理。

## 明确边界

这是一个 0.x 首发版本，不提供 Controllers、Decorators、Dependency Injection、文件系统路由扫描、自动 `next.config.ts` 注册或新的 Router。Next.js `proxy.ts` 仍然是独立边界。

首发包版本直接固定为 `0.1.0`。后续公开 API 或行为变更必须创建非空 Changeset，并按照维护者[发布清单](../../release/release-checklist.md)执行版本流程。

## 验证记录

本地发布门禁已通过：全部 package tests、严格类型检查、ESLint、Prettier、包构建、
packed external consumer 校验，以及 Next.js 15/16 production 和 Turbopack development
冒烟测试均通过。Next 15 的真实 Edge App Route 仍会触发 Next.js 自身关于静态生成限制的
提示；Next 16 的 Edge Runtime 弃用提示和 Next 15 的 ESLint plugin 检测提示已经不再出现。
