## Maintainer checklist

- [Release checklist](./release-checklist.md)

The release process is intentionally explicit. A version is published only
after the repository checks pass, the release commit is on `main`, npm scope
ownership is confirmed, and the protected `npm-release` environment approves
the workflow.
